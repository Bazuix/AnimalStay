# 🐾 AnimalStay

A pet hotel management system (for dogs, cats, etc.).  
The application allows you to manage stays, rooms, pets, and owner data.

---

## 📌 Features

- 🔐 User authentication (login & register with JWT)
- 🐶 Pet management (CRUD)
- 🏨 Room management
- 📅 Reservations and pet stays
- 🗺️ Room Map view
- 📊 Dashboard with active stays

---

## 🛠️ Technologies

### Backend
- Node.js
- Express
- Prisma ORM
- MySQL (XAMPP)
- JWT (authentication)
- bcrypt (password hashing)

### Frontend
- React
- Vite
- TypeScript
- Axios

### Testing
- Jest (backend)
- Vitest (frontend)
